Реальных запросов наружу нет. Реализация: `app/checks.py`, данные: `fixtures/`. Все демо-ИНН имеют верную контрольную сумму (она проверяется при отправке заявки).

| ИНН | Реестр | БКИ |
|---|---|---|
| есть в `fixtures/mock_*.json` | из файла | из файла |
| начинается с `9999` (демо: `999912345603`) | ИП прекратил деятельность (стоп-фактор, отказ) | по умолчанию |
| начинается с `0000` (демо: `000012345627`) | сбой сервиса | сбой сервиса (ручное рассмотрение) |
| любой другой | действует | кредитов и просрочек нет |

Демо-истории:
- `770601234529` (Иванов): чистая история, 0 кредитов.
- `770501234532` (Смирнов): чистая история; высокая долговая нагрузка по заявке даёт серую зону.
- `771201234501` (Петров): действующая просрочка 45 000 ₽ (стоп-фактор) и две просрочки за год.
- `780201234584`: три кредита и две просрочки, текущей просрочки нет (красная зона по баллу).
